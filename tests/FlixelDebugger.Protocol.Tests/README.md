# FlixelDebugger.Protocol.Tests

xUnit tests for `FlixelDebugger.Protocol`.

## Fixtures

The `Fixtures/` folder holds binary test vectors for the wire protocol. They are copied unchanged
from the FlixelGDX framework repository, from
`flixelgdx-test/src/test/resources/org/flixelgdx/debug/remote/fixtures/`. The `README.md` inside the
folder is generated by the framework's tests and lists the exact values every `.bin` file encodes.

The framework repository is the source of truth. **When the protocol changes (`DEBUG_PROTOCOL.md`
and the Java tests), re-copy the whole folder here** and update the matching tests. The fixture files are copied to the
test output folder at build time (`None` items with `CopyToOutputDirectory`), and the tests read them from
`Fixtures/` next to the test assembly.

Every `.bin` file is covered twice:

1. A test decodes it and asserts the values from the fixtures README.
2. A test re-encodes the decoded model and asserts the bytes match the file exactly.

A guard test fails if a new `.bin` file appears without a matching entry in the round-trip list.
